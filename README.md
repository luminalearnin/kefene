# Kefene — editorial demo

A mobile-first, static storefront concept for Kefene, based on the public Instagram profile `@kefeneoffline` and the current product categories visible on Kefene's official shop. This is a demo, not an official Kefene site or a functioning store. Shop links open the real storefront; no cart or payment is simulated.

## Run locally

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8000`.

## Publish

The project is designed for GitHub Pages at `https://luminalearnin.github.io/kefene/`.

## Image credits

Kefene product photographs were discovered in public search results for Kefene merchandise. Editorial mood photographs are from Unsplash and are used as fashion inspiration, not as representations of Kefene products. All photos are stored locally under `assets/`.
