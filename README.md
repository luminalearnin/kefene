# Kefene demo storefront

A responsive, static shopping demo for Kefene. The catalog includes knitwear, T-shirts, shirts, denim, lowers and outerwear, with category filters, search, size selection, a local shopping bag, a sign-in preview and a no-payment checkout preview.

## Demo data

The three Marino knit sweater colorways and their listed price presentation were carried over from the existing catalog. Additional sample listings and prices are illustrative UI content only; they are not a statement of current stock, SKU names or pricing. Confirm product names, fit, size runs, prices and availability with Kefene before using the site as a live store.

Cart contents are stored in browser local storage. Sign-in and order completion are preview interactions only: no account is created, no email is saved, no order is transmitted and no payment is collected.
