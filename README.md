# Kefene — demo storefront

A static, mobile-first storefront demo for Kefene. It includes a small apparel catalog, product size selection, search and filters, a locally persisted shopping bag, a sign-in preview, and a simulated Buy Now flow.

All interactions are front-end demo behavior. Sign-in does not create accounts or retain email addresses. Checkout does not submit orders or take payments. No external shop links or services are used.

## Run locally

Open `index.html` or serve the project directory with `python3 -m http.server 8000`.

## Publish

GitHub Pages publishes the root of the `main` branch at `https://luminalearnin.github.io/kefene/`.

Product photography is stored under `assets/`.
